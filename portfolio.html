3-1 · Overview

서비스 개요 &
배경

KT 멤버십은 KT 통신 가입자를 대상으로 포인트 적립, 할인 쿠폰, 제휴 혜택을 제공하는 앱 서비스입니다. 수백만 명의 실사용자를 보유한 서비스임에도 불구하고, 혜택 인지율이 낮고 메뉴 구조가 복잡해 사용자가 실제 혜택을 활용하지 못하는 문제가 반복적으로 제기되었습니다. 본 프로젝트는 UX 관점에서 정보 구조를 재설계하고, UI를 현대적으로 개선하여 실질적인 앱 가치 상승을 목표로 합니다.

3-2 · Problem Definition

무엇이 진짜 문제인가

스토어 리뷰 200건 분석 및 휴리스틱 평가를 통해 핵심 Pain Point를 도출했습니다. "혜택이 있는 줄 몰랐다", "찾기 어렵다", "쓰기 불편하다"는 응답이 전체의 68%를 차지했습니다.

핵심 인사이트: 기능이 없는 것이 문제가 아니라, 있는 기능을 발견하지 못하는 정보 구조(Information Architecture)가 문제였습니다. 사용자는 평균 3.2회의 탭 이동 후에야 원하는 혜택 화면에 도달할 수 있었습니다.

Before — 주요 문제점

  • 뎁스 3단계 이상의 복잡한 내비게이션
  • 혜택 카테고리 분류 기준 불명확
  • 포인트 잔액과 사용처 연결 부재
  • 시각적 위계(계층) 부재로 CTA 미인지
  • 중복된 기능 메뉴로 인한 사용자 혼란

After — 개선 방향

  • 핵심 기능 2단계 이내 접근 보장
  • 사용 맥락 기반 혜택 카테고라이징
  • 포인트 → 즉시 사용 원스텝 플로우
  • 명확한 시각 위계로 CTA 강조
  • 중복 제거 후 Bottom Nav 재구조화

3-3 · UX Strategy & Process

해결 과정 &
구조 설계

정보 구조(IA) 재설계를 출발점으로, 핵심 유저 저니맵에서 병목 구간을 특정하고 플로우 차트를 통해 최단 경로를 설계했습니다.

01
리서치
앱스토어 리뷰 200건 분석 + 휴리스틱 평가 10항목
02
IA 재설계
기존 5개 탭 → 3개 탭으로 통합. 맥락 기반 그룹핑
03
와이어프레임
핵심 플로우 5개 시나리오 작성. 병목 구간 3개 해소
04
UI 디자인
Figma 컴포넌트 시스템 구축. 라이트/다크 대응

3-4 · UI Design & Design System

비주얼 &
시스템

Figma Variables와 Auto Layout을 활용해 컴포넌트 라이브러리를 구축했습니다. 버튼, 카드, 내비게이션 등 주요 컴포넌트의 Default / Hover / Active / Disabled 상태를 정의하고, 타이포그래피 스케일과 컬러 토큰을 체계화했습니다.

🏠 홈 — 혜택 피드
💳 포인트 — 원스텝 사용
🎁 혜택 — 맥락 카테고리
⚙️ 디자인 시스템 — 컴포넌트

반응형 대응: 컴포넌트 구조를 iOS/Android 가이드라인에 맞게 이중 설계하여 플랫폼별 터치 타겟(최소 44px)과 간격 시스템을 별도 정의했습니다.

구현 협업 및 회고

초기 설계안의 탭 전환 인터랙션(모션 블러 효과)은 저사양 기기에서의 성능 이슈를 고려해 CSS opacity + translate 조합으로 최적화 방향을 수정했습니다. 개발 스펙 문서 작성 과정에서 디자인 토큰의 중요성을 직접 체감했습니다.
